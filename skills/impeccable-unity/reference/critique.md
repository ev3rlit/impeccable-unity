# Critique

## Use and input
Evaluate a named surface's design, not its technical compilation status. Input includes its user/task, actual content, UI state and source or images. Resolve what a successful user action is before judging style.

## Read
Read unity-design.md, design-policy.md and unity-review.md plus the product/design context and target. For Unity the normal path is native design review; a web detector is not applicable and is not a degraded result.

## Work
1. Form a grounded first impression: hierarchy, task clarity, information architecture, cognitive load, affordances, emotional fit and product specificity. Preserve intentional familiarity on Operate surfaces.
2. Walk the primary task and relevant persona/device context. Find the highest-impact confusion, competing focal points, hidden states and broken visual promises. Check anti-slop policies with their actual conditions, not blanket effect bans.
3. Identify strengths worth preserving. For each material finding provide target/location, observed evidence, user impact, P0–P3 priority and a concrete improvement direction.
4. Offer the appropriate next command. If scores help, state applicable dimensions and evidence; leave unobserved dimensions unscored and do not imply a standardized benchmark.

## Boundary and output
Report in conversation only. No source fixes, DESIGN.md rewrites, hidden snapshots or critique-history files. Do not execute audit/optimize as a side effect or invent a detector pass.

## Verify and fallback
Cross-check a suspected issue against relevant states and source before reporting it as fact. Without Editor/images deliver a source-grounded design review with explicit appearance limits. A code inspection cannot prove contrast at a rendered pixel or a touch interaction.

## Official example and Unity transfer

Read the [critique Before/After case](before-after-cases.md#critique) for the source, concrete problem, preserved properties and acceptance criteria. The example teaches a correction, not an art preset. The After is a sourced diagnostic; do not silently apply its recommendation.
